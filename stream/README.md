# Трансляція викладача: як запустити

Схема: **OBS → тимчасовий сервер Hetzner (MediaMTX + Caddy) → WebRTC → браузери студентів**. Затримка менше 1 с.
Сервер створюється перед заняттям і видаляється після нього. Hetzner бере погодинну оплату, поки сервер існує, тож година трансляції коштує копійки.

На сайті, поки трансляція йде, у заголовку графіка є кнопка «● Трансляція». Коли трансляції немає, кнопки немає.

---

## Перед заняттям (≈10 хв)

### 1. Створити сервер
console.hetzner.cloud → проєкт → **Add Server**:
- **Location:** Helsinki або Falkenstein;
- **Image:** Ubuntu 24.04;
- **Type:** найдешевший (Shared vCPU, x86 або Arm);
- **Networking:** Public IPv4 увімкнено;
- **Cloud config:** вставити весь вміст `stream/cloud-init.local.yml` (див. «Пароль OBS» нижче).

**Create & Buy now**, потім скопіюйте IPv4-адресу сервера.

### 2. Прописати IP на сайті
```bash
stream/set-server.sh 1.2.3.4                # ← IP нового сервера
git commit -am "Broadcast server: 1.2.3.4" && git push
```
Скрипт сам виведе адресу для перевірки й адресу для OBS.

### 3. Перевірити сервер
Через 2–3 хв відкрийте `https://1-2-3-4.sslip.io` (IP через дефіси).
Має з'явитися «Broadcast server». Якщо сторінка не відкривається, зачекайте ще хвилину: сервер ще встановлює програми або отримує сертифікат.

### 4. OBS
**Налаштування → Трансляція:**
- Служба: **WHIP**
- Сервер: `https://1-2-3-4.sslip.io/live/whip`
- Bearer-токен: `obs:<пароль>`. Пароль — значення `pass:` у `stream/cloud-init.local.yml`.

Сервер змінюється щоразу. Токен лишається той самий, якщо щоразу використовувати той самий `cloud-init.local.yml`.

**Почати трансляцію.** Протягом 30 с у студентів з'явиться кнопка «● Трансляція».
Перевірте з телефона через мобільний інтернет.

## Після заняття

1. Зупиніть трансляцію в OBS.
2. Hetzner → сервер → **Delete**. Вимкнути замало: вимкнений сервер теж оплачується.
3. Вимкніть трансляцію на сайті:
   ```bash
   stream/set-server.sh off
   git commit -am "Broadcast off" && git push
   ```
   Так сайт перестане звертатися до старої IP. Її згодом може отримати чужий сервер.

## Пароль OBS (`cloud-init.local.yml`)

`stream/cloud-init.local.yml` — це `cloud-init.yml` з уже вписаним паролем. Файл ігнорується git і зберігається лише локально.
Якщо його немає (новий комп'ютер, свіжий clone), створіть з новим паролем:
```bash
sed "s/__OBS_TOKEN__/$(openssl rand -hex 20)/" stream/cloud-init.yml > stream/cloud-init.local.yml
grep "pass:" stream/cloud-init.local.yml | head -1     # новий пароль → у Bearer-токен OBS
```

## Налаштування OBS «Вивід» (один раз)

Режим «Розширений»:
- Кодувальник: x264 або Apple VT H264;
- CBR, **2000 кбіт/с**;
- інтервал ключових кадрів **1 с**;
- для x264: профіль `baseline`, tune `zerolatency`.

**Відео:** 1280×720, 30 FPS. Звук передається; якщо він не потрібен, вимкніть мікрофон у мікшері OBS.

## Як дивитися самому

- Як студент: просто сайт, кнопка «Трансляція».
- З `?camera`: у списку джерел є «📡 Трансляція викладача» поруч з вашими камерами.
- Локально: `python3 -m http.server 8000` у корені репозиторію → `http://localhost:8000/index.html`.
  Через `file://` не працює: сторінка має origin `null`, а MediaMTX не віддає для нього CORS-дозвіл.
- Інший сервер без коміту: `index.html?stream=https://1-2-3-4.sslip.io/live/whep`.

## Якщо щось не працює

| Симптом | Що перевірити |
|---|---|
| `https://…sslip.io` не відкривається понад 5 хв | Hetzner → сервер → Console: `cloud-init status --long`, `journalctl -u caddy` |
| OBS: помилка підключення | адреса закінчується на `/live/whip`, токен починається з `obs:` |
| Кнопки на сайті немає | GitHub Pages ще не оновився (1–2 хв після push); OBS справді транслює |
| Кнопка є, але відео немає | Firewall Hetzner (якщо вмикали): потрібні TCP 80/443 і UDP+TCP 8189 |
| Лог трансляції | на сервері: `journalctl -u mediamtx -f` |

## Безпека

- Публікувати можна лише з паролем OBS. Без нього сервер відповідає 401.
- Назовні відкриті тільки `/live/whip` і `/live/whep`. Сигналізація MediaMTX слухає лише localhost.
- IP сервера не секрет: браузер кожного глядача мусить його знати.
