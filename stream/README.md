# Трансляція викладача

Схема: **OBS → сервер Hetzner (MediaMTX + Caddy) → WebRTC → браузери студентів**. Затримка менше 1 с.
Поки трансляція йде, на сайті в заголовку графіка з'являється кнопка «● Трансляція».
Коли трансляції немає, кнопка прихована.

```
OBS ──WHIP + токен──▶ Caddy (HTTPS :443) ──▶ MediaMTX ◀──WebRTC (UDP/TCP 8189)── глядачі
                                                ▲
                          сайт: POST /live/whep ┘
```

Домен — `<ip-через-дефіси>.sslip.io`. Він завжди вказує на IP сервера, реєструвати нічого не треба.

## Створення сервера (один раз)

1. На console.hetzner.cloud створіть проєкт і додайте сервер:
   - **Location:** Helsinki або Falkenstein (найближче до України);
   - **Image:** Ubuntu 24.04;
   - **Type:** найдешевший (Shared vCPU, x86 або Arm), цього з запасом вистачає на 100 глядачів;
   - **Networking:** Public IPv4 увімкнено;
   - **Cloud config:** вставте вміст `stream/cloud-init.local.yml`. Пароль OBS у ньому вже вписаний.
     Якщо цього файлу немає, візьміть `stream/cloud-init.yml` і замініть `__OBS_TOKEN__` довгим паролем (лише літери й цифри).
2. Через 2–3 хвилини відкрийте `https://<ip-через-дефіси>.sslip.io` (наприклад, `https://203-0-113-7.sslip.io`).
   Якщо бачите «Broadcast server», сервер готовий і сертифікат отримано.
3. На сайті в `index.html` пропишіть цю адресу в `STREAM_URL` (`https://…sslip.io/live/whep`).

Firewall Hetzner вмикати не обов'язково. Якщо вмикаєте, дозвольте TCP 80, TCP 443, UDP 8189, TCP 8189 і SSH.

## OBS (один раз)

- **Налаштування → Трансляція**
  - Служба: **WHIP**
  - Сервер: `https://<ip-через-дефіси>.sslip.io/live/whip`
  - Bearer-токен: `obs:<пароль із cloud-init>`
- **Налаштування → Вивід** (режим «Розширений»)
  - Кодувальник: x264 або Apple VT H264
  - CBR, **2000 кбіт/с**
  - Інтервал ключових кадрів: **1 с**
  - Для x264: профіль `baseline`, tune `zerolatency`
- **Відео:** 1280×720, 30 FPS

Звук також передається. Якщо він не потрібен, вимкніть мікрофон у мікшері OBS.

## Кожна трансляція

«Почати трансляцію» в OBS. Протягом 30 с у студентів з'явиться кнопка «Трансляція».
Сервер працює постійно, на ньому нічого запускати не треба.

## Обслуговування (через SSH)

```bash
systemctl status mediamtx caddy       # стан сервісів
journalctl -u mediamtx -f             # лог трансляції (хто підключився)
cat /etc/broadcast-domain             # домен сервера
```

Змінити пароль OBS: відредагуйте `/etc/mediamtx/mediamtx.yml` і виконайте `systemctl restart mediamtx`.

Якщо сервер видалити, IP зміниться, а з ним і домен. Тоді треба оновити `STREAM_URL` на сайті й адресу в OBS.

## Локальна перевірка без сервера

Запустіть MediaMTX на своєму комп'ютері з конфігом з `cloud-init.yml`. Потім у корені репозиторію виконайте
`python3 -m http.server 8000` і відкрийте `http://localhost:8000/index.html?stream=http://localhost:8889/live/whep`.
Через `file://` не працює: сторінка має origin `null`, а MediaMTX не віддає для нього CORS-дозвіл.

## Безпека

- Публікація лише з паролем OBS. Без нього сервер відповідає 401.
- Назовні через Caddy відкриті лише `/live/whip` і `/live/whep`. Сигналізація MediaMTX (8889) слухає тільки localhost.
- Пароль зберігається в `/etc/mediamtx/mediamtx.yml` (лише root) і в `stream/cloud-init.local.yml`. Цей файл ігнорується git, у репозиторій не потрапляє.
